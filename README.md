# Expense-Tracker
A simple expense tracker to log daily spending in ₹, view monthly totals and see a category-wise breakdown. Built with HTML, CSS and JavaScript.

A lightweight expense tracker I built to understand where my money goes each month. You can add expenses with a category, date and note, switch between months, and see a visual breakdown of your spending. Data is saved in the browser, so no sign-up is needed. It supports dark mode and works on mobile.

Tech used: HTML, CSS, JavaScript, localStorage, GitHub Pages

Expense Tracker: log, categorise and visualise your monthly spending.
